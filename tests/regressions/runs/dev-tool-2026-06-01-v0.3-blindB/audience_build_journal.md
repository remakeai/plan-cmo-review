## Anti-vanity reminder

Per SKILL.md Section 8, the following metrics are NOT to be optimized for:
- Total GitHub stars (use velocity instead)
- Twitter follower count
- HN upvote count
- Total signups (use retention)

If a weekly journal entry leads with one of these, rewrite it leading with: MRR, paying logos, email subs, retention of paying cohort, beta dependence rate.
