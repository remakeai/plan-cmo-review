# Threadline — Launch Playbook

**Companion to `marketing_plan.md`.** Sequenced, multi-channel launch under the recommended PMF-signal gate (NOT calendar gate).

## Pre-conditions (do NOT launch unless all are true)

1. **PMF gate (Vohra "very disappointed" test):** ≥40% of design-partner cohort answer "very disappointed if I could no longer use this." Sample size ≥10 active design-partner respondents.
2. **Reference threshold:** ≥3 design-partner companies committed to public reference status (logo + quote on landing page).
3. **Procurement readiness:** SOC 2 Type I report in hand; Type II observation period started; SSO live with Okta + Google Workspace.
4. **Wedge clarity:** Landing page answers "why switch from Linear?" in one sentence with proof from a reference customer.
5. **Audience runway:** ≥12 LinkedIn long-form posts from each founder; ≥2 podcast appearances scheduled; Pragmatic Engineer slot booked for Day 0 or Day 0+14.

If any condition fails, extend audience-build sprint by 30 days.

## Sequence

### T-90 (Day -90)
- Begin Section 4 audience-build sprint (see marketing_plan.md Section 4).

### T-60
- Begin design-partner concierge onboarding (5-10 named teams from ex-Google peer mining).
- Confirm Pragmatic Engineer sponsorship slot for Day 0 or Day +14 window.

### T-30
- Lock 3 design-partner reference quotes for launch landing page.
- Confirm landing page V1 with wedge sentence + reference quotes + clear CTA.
- Run dry-run Show HN title in private group of 5 trusted HN-savvy friends; iterate title.

### T-14
- Each founder DMs ~25 ex-Google peers personally: "Launching Threadline in 2 weeks. 5 teams already using it. Want a private demo?"
- Submit Show HN draft to 3 friends for feedback on title and first paragraph.
- Schedule LinkedIn posts.

### T-7
- Soft pre-announce to 50-person personal email list.
- Final landing page polish.
- Test trial-signup + payment flows end-to-end.

### T-3
- LinkedIn build-in-public post from Founder A: "We've been building Threadline for [N] months. Launch Tuesday. Here's what 5 design partners taught us." Include screenshot, no link yet (links suppress reach).
- Second LinkedIn post from Founder B (technical angle): "How we built Threadline's [technical thing]." Establishes credibility for the HN crowd.

### T-1
- Hold. Rest. Pre-write Day 0 Show HN comment responses for likely critique vectors (pricing, free tier, comparison to Linear, why-now).

### Day +30

### Day +60

### Day +90

## Risk callouts

- **HN miss:** Not fatal because awareness is multi-channel. Pragmatic Engineer + LinkedIn + warm intros + podcasts are the real conversion engine.
- **Pragmatic Engineer pass:** High impact if it happens — Lenny's, Software Engineering Daily, and LeadDev are backup high-quality slots.
- **LinkedIn algorithm shift:** Founders' warm-intro infrastructure operates independently of algorithm.
- **Wedge unclear at launch:** If landing page fails the "one sentence" test, delay launch. Don't ship with unclear positioning.

## Decision tree if launch underperforms

- **Day 30: <3 paying mid-market customers** → SOC 2 + procurement-readiness path is the bottleneck, not marketing. Pause marketing spend; fix procurement readiness; relaunch at Day 90.
- **Day 30: 3-5 paying mid-market customers** → Plan is working. Double down on Pragmatic Engineer + reference flywheel.
- **Day 30: >5 paying mid-market customers** → Validate it's the RIGHT cohort (50-500 person companies, not small teams). If wrong cohort, the conversion is misleading.
- **Day 60: <10 paying customers total** → Revisit motion choice. Strong signal that sales-led mid-market motion needs a real AE hire or fractional sales help.
